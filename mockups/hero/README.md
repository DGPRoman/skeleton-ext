# Hero placeholders

Placeholder images for developing the hero section. Not synced to Shopify — the CLI
and the GitHub integration only pick up `assets`, `blocks`, `config`, `layout`,
`locales`, `sections`, `snippets`, `templates`. Upload them manually in
Admin → Content → Files.

| File | Size | Ratio | Use |
|---|---|---|---|
| hero-desktop-1.jpg | 3000×1500 | 2:1 | desktop, variant 1 (teal → sand) |
| hero-mobile-1.jpg | 1500×2000 | 3:4 | mobile, variant 1 |
| hero-desktop-2.jpg | 3000×1500 | 2:1 | desktop, variant 2 (plum → coral) |
| hero-mobile-2.jpg | 1500×2000 | 3:4 | mobile, variant 2 |

The scrim is baked into the images: on the left for desktop, at the bottom for
mobile — where the text is meant to sit.
