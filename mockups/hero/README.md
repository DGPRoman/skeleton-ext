# Hero placeholders

Placeholder images for developing the hero section. Not synced to Shopify — the CLI
and the GitHub integration only pick up `assets`, `blocks`, `config`, `layout`,
`locales`, `sections`, `snippets`, `templates`. Upload them manually in
Admin → Content → Files.

| File | Size | Ratio | Use |
|---|---|---|---|
| hero-desktop-1.jpg | 3000×1500 | 2:1 | desktop, variant 1 (teal → sand) |
| hero-mobile-1.jpg | 1500×2000 | 3:4 | mobile, variant 1 |
| hero-desktop-2.jpg | 3000×1500 | 2:1 | desktop, variant 2 (plum → coral) |
| hero-mobile-2.jpg | 1500×2000 | 3:4 | mobile, variant 2 |

The scrim baked into the images — on the left for desktop, at the bottom for
mobile — is left over from an earlier design that carried text over the banner.
It is harmless now, and it is why the images look shaded on one side.

The ratios match two of the section's height options: 2:1 is Medium on desktop,
3:4 is Large on mobile. Both also work under Adapt, which takes the file's own
proportions and never crops.
